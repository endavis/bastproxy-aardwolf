# The a102 Plugin

Aardwolf uses telnet option 102 to turn on game features such as channel tags, spellup tags, the
prompt and quiet mode, and to report state changes such as the character becoming active. The
`a102` plugin owns that option through bastproxy's generic telnet-option hook
(`libs.net.protocols:telopt.*`, bastproxy ADR-0012), so other plugins and clients can share it.

## Loading

The package registers itself as a bastproxy plugin source, so the plugin id is
`plugins.aardwolf.a102`:

```text
#bp.core.pluginm.load plugins.aardwolf.a102
```

The plugin registers option 102 in `after_load`. Unloading it releases the option.

## Counting rules

Each "on" request adds one to the option's count and each "off" request takes one away, never going
below zero. The MUD hears about only two changes:

- the count going from 0 to 1 sends `<option> 1`;
- the count going back to 0 sends `<option> 2`.

Further "on" calls and an "off" at a count of 0 send nothing, and an "off" at 0 does not create a
count. Several plugins can share an option without turning it off under each other.

A toggle made while option 102 is not enabled on the MUD link only updates the counts. When
`ev_libs.net.mud_telopt_102_enabled` fires, on the first connect or a reconnect, the plugin sends
the current state of every counted option. There is one count per known option and no queue of
requests. The counts survive a plugin reload.

## Tags

Some tags are turned on with the MUD's `tags <name> on|off` command, not with an option 102 flag.
`SCAN` is one. The names differ from the option names above (`SCAN`, `SPELLUPS`, ... against
`SPELLUPTAGS`), and the global `tags on` must also be on. The `tag.toggle` API counts requests the
same way as `option.toggle`, with these differences:

- A name is one alphabetic word, upper-cased; anything else returns `False` with a warning.
- The command is sent only while the character is active. Before that a toggle only counts, and
  the `character_active` hook sends `tags <name> on` once for each counted tag.
- The plugin remembers the tags it turned on during this connection. A disconnect forgets them, so
  the next connection sends each one once. A reload keeps them, so nothing is sent twice.
- `tags <name> off` goes out only for a tag it turned on during this connection: on the last
  release, or on a real unload while the character is active. A reload sends nothing. A user who
  had the tag on before loses it when the last plugin that asked for it is unloaded.

## Unloading

On a real unload, while option 102 is enabled on the MUD link, the plugin sends "off"
(`<option> 2`) for every option with a count above 0, and nothing for options with a count of 0.
The `uninitialize` hook runs before the base plugin's hook that unregisters the plugin's telnet
options, so the sends are not refused. Nothing is sent when option 102 is not enabled.

On a reload the plugin sends nothing: the counts are saved, and after the plugin loads again the
counted state is sent once more. The base plugin's `is_reloading_f` tells the two apart.

## Client toggles

A client's option 102 subnegotiation (`ev_libs.net.client_telopt_102`) of two bytes, a known
option number and a flag of 1 or 2, goes through the same counts. Anything else is ignored, as is
data from a view-only client.

## APIs

| API | Description |
| :--- | :--- |
| `plugins.aardwolf.a102:option.toggle(name, enable) -> bool` | Count one on or off request. Returns `False` and logs a warning for an unknown name. |
| `plugins.aardwolf.a102:tag.toggle(name, enable) -> bool` | Count one on or off request for a MUD `tags` tag. Returns `False` and logs a warning for an invalid name. |
| `plugins.aardwolf.a102:payload.send(payload) -> bool` | Send a raw option 102 payload to the MUD (wraps `telopt.send`); `False` when nothing was sent. |

```python
self.api("plugins.aardwolf.a102:option.toggle")("SPELLUPTAGS", True)
```

## Events

Every two-byte subnegotiation from the MUD raises both events with the args `option` and `flag`.
The core still forwards the data to clients.

| Event | Raised |
| :--- | :--- |
| `ev_plugins.aardwolf.a102_mud_data` | for every two-byte message |
| `ev_plugins.aardwolf.a102_mud_option_<n>` | for the messages of option number `n`; added on first use |

For example, option 100 carries the character state, so `ev_plugins.aardwolf.a102_mud_option_100`
with `flag` 3 means the character is active.
